# **Crysword使用说明**

本工具支持以密码python库的形式使用，目的在于减少最基础的密码程序编写量，以及快速破解一些基础加密

本工具配套完整的功能介绍，包含可以调用的函数类别，功能，同时配套快速连接到wsl里面的sage调用其功能，如果缺失sage环境以及其他密码工具环境，请自行补全，本工具开发中没有没有设计环境自动补全

本工具后续将包括供给AI的基础密码学embedding,供快速解密密码签到题目，以及给难题解题时提供小模块参考，这个需要单独联系作者

本工具为个人编写以及以往学习时从老师傅，公开git仓库收集的示例脚本，AI负责构建路径支持，以及debug帮助，出现错误属于正常现象，出现问题可以邮箱联系作者：blsword.ffs@gmail.com

本工具的算法优化，密码解密皆只是基于作者能力以及收集，存在优化空间，有想法的可以联系作者，以及有想要增加功能的开发者也欢迎

本工具开发目的是帮助非路径的师傅快速解密基础密码题目，以及帮助同路径的师傅减少代码编写数量，如果是刚入门想要学习的师傅，可以把里面的解密函数看作示例，但请不要依赖于工具解密误以为为自身能力，本工具仅起到辅助效果

本工具仅收录了简单题目的快捷求解，功能十分有限，并且还处于不断开发中，遇见bug属于正常现象（）

## 完整配置说明：

sageworker为导入桥接模块，sagewoker_config.json为配置页，存储sage于虚拟机的位置供启动使用,需要按照指导手动配置，hashcat等虚拟机功能同

  "wsl_distribution": "Ubuntu",

  "sage_path": "sage",      

上述2行为配置行，目前可能虚拟机只支持乌班图，师傅可以自行修改，path填写虚拟机内路径

sage存储好后可以调用from crysword import sage检查



pyproject.toml为标准python库提示文件，使用以下Powershell安装进Python环境：

pip install -e .         #覆盖型下载

pip uninstall crysword  #删除

下载完毕后同一文件夹下会出现crysword.egg-info的项目源数据目录，正常情况下不要管



工具中有的解密函数可能具体情况具体改变才能使用，可以至于同一目录下更改配置系数后使用

MT19937矩阵数据.sobj是MT攻击需要的矩阵数据，可用范围仅为标准MT19937加密



功能菜单为调用函数指导，功能辨别为供密码学功底一般的师傅识别签到题特征指导

另：有的函数有检查，有的没有，是因为有的是作者之前写错过所以写了检查，有的没有则是因为作者用的时候一遍过（），汗，这可能会带来bug以及使用体验问题作者先orz了
